# 口播广告制作

## 强制执行职责链

本 Skill 负责提出完整的制作要求和验收标准：先根据用户目标与全部素材，向 LLM 下达一套统一要求，明确如何组合真人/产品展示、参考视频结构、口播、字幕、MG 动效和混合叠加；再由 LLM 按要求执行；执行完成后，由本 Skill 对照制作要求和验收标准检查结果，发现问题就提出针对性修复要求。LLM 不得把这些内部组成部分改成让用户选择的路线菜单，除非用户明确要求改变创意方向。

本 Skill 用于为任何商品、服务或商业产品制作短口播广告视频。参考素材可以提供结构、节奏、演示逻辑、人物呈现、视觉包装或动效语言；最终画面必须重新生成或重新制作，不做逐帧复制。

## 步骤 1：接收素材并做阻塞检查

确认商品或服务、目标客户、卖点、促销信息、用户台词、参考素材、时长、画幅、分辨率、语言、音色、字幕和 MG 动效需求。

只有在缺失信息会影响可靠制作时才弹窗询问：

1. 缺少可用商品或服务信息：询问是根据可见参考内容先做、提供资料、上传截图，还是粘贴核心卖点。
2. 用户要求参考驱动但没有参考素材：询问是上传参考，还是根据文字描述继续。
3. 参考素材超过所选模型限制：询问使用已确认片段、由用户指定时间段，还是不使用该参考。
4. 价格、折扣、速度、保证、认证、效果或结果无法核实：询问用户确认，或改写为保守表达。
5. 制作要求涉及品牌视觉、产品界面、UI 素材或明确图形语言，而现有素材不足以决定结果：询问使用干净的中性视觉系统，还是补充品牌/界面素材。

不得自行编造商品事实、价格、保证、认证、性能数据或绝对化结果。


本 Skill 必须先根据用户需求和全部素材，向 LLM 下达一套统一制作要求，明确真人/产品展示、参考视频结构、口播、字幕、MG 动效和混合叠加如何共同服务于目标。LLM 按要求执行；执行完成后，本 Skill 再对照制作要求和验收标准检查结果，必要时提出针对性修复。这些是内部制作组成部分，不是给用户选择的路线菜单。除非用户明确要求改变创意方向，不得让用户在这些模式之间自行选择。

## 步骤 2：分析参考素材和产品资料

只提取制作需要的证据：

- 主体或产品类别、使用方式、演示动作和卖点呈现。
- 真人口播、画外音、手部展示、生活方式、开箱、测评、教程、对比、UI 或混合形式。
- 开头钩子、镜头顺序、节奏、转场、特写、产品互动、CTA、字幕和图形包装。
- MG 参考中的信息层级、功能状态变化、流程/图解逻辑、图标行为、文字强调和转场节奏。
- 景别、镜头行为、场景、媒介、可复用视觉语言和技术兼容性。
- 时长、画幅、分辨率及素材限制。

将每个参考素材视为有明确贡献的来源。只保留用户要求或兼容的身份、结构、动作、设计、世界、风格、布局或图形逻辑。未经明确授权或技术适配，不复制具体人物、地点、原画面、Logo、产品承诺或无关载体元素。

## 步骤 3：编写短视频脚本和信息层级

根据确认时长编写紧凑台词。10–15 秒广告优先包含：

1. 前三秒钩子或痛点。
2. 商品/服务类别和一至两个具体利益点。
3. 有依据时加入可视化演示、使用场景、对比、功能解释或证明。
4. 已确认的优惠信息或行动理由。
5. 明确 CTA。

区分“说出来的信息”和“画面显示的信息”。由 LLM 判断哪些内容口播、哪些关键词做动态字、哪些卖点用图形/界面解释、哪些参考视频动作需要转化为全新画面、哪些内容只放字幕，并把它们组合成统一的短广告表达。根据时长控制屏幕文字数量。

使用短句、自然停顿和能在时长内读完的语言。用户要求原文时逐字保留。证据不足时保守表达，并标记需要用户确认的广告主张。

## 步骤 4：规划画面、声音与 MG 动效

把台词拆成紧凑镜头。每个镜头明确景别、镜头行为、主体动作、产品互动、转场、对应台词、声音方向和字幕时间。

真人口播广告要保持人物跨镜头一致；产品广告要用特写、手持、使用、场景或前后对比让产品清楚可见；服务广告可以用代表性案例说明能力，但不得暗示没有依据的客户结果。

本 Skill 下达的统一制作要求必须让 LLM 评估 MG 图形如何提升理解、节奏、信息层级或 CTA 冲击力，并执行合适的动效层；LLM 不得通过改选其他路线而省略该要求。本 Skill 随后按简报和验收标准验收 MG 表达。动效层要求包括：

- 建立视觉层级：人物/产品优先，图形辅助说明。
- 只动画化有意义的元素：关键词、利益点、价格/优惠、UI 状态、流程图、图标、指示线、进度提示和 CTA。
- 根据表达需要使用跳字、滑入、缩放、遮罩、数字递增、标注框或跟随动效，不为了热闹而堆动效。
- 产品、软件或服务讲解可用功能卡片、流程串联、对比面板、UI 变化或图形隐喻，不用大段文字堆叠。
- 字幕必须清晰、同步、位于安全区域，不能遮挡商品、人物面部、手部或关键动作。
- 纯 MG 口播动画先形成可审阅的提示词/脚本方向，写清视觉系统、场景顺序、口播、文字层级、转场、声音和时间；当流程或用户要求需要审核时，确认后再进入高成本生成。

用户提供了独特品牌、UI、产品或参考视觉时，不得套用库存 MG 模板。没有品牌系统时使用干净的中性视觉系统，并简要说明这一选择。

## 步骤 5：LLM 自动编排与制作方式

优先遵循用户指定的模型、时长、画幅、分辨率和参考方式。未指定时，由 LLM 根据参考素材、商品和全部表达目标自动编排适合的短视频制作方式。模型支持时使用多模态参考，并为每个参考明确用途。除非用户明确要求，不把普通参考素材当作开头或结尾关键帧。

在组合表达中，保持商品、人物、UI、文字层级、图形语言、参考转化动作和口播跨镜头一致。需要准确可读文字时，使用独立的确定性文字、口播或合成处理。

最终时长必须符合所选模型限制。若素材因时长、格式或安全限制不能直接使用，要说明具体限制并询问用户选择，不得静默丢弃参考素材。

## 步骤 6：Skill 验收

LLM 执行完成后，本 Skill 必须检查：用户要求的信息是否完整，所有指定参考是否按既定用途使用，人物/商品是否连续，MG 是否帮助理解而不是喧宾夺主，字幕是否匹配确认台词和时间，声音是否与画面一致，广告主张是否有依据。只有验收通过的结果才能交付。

## 步骤 7：修复文字、声音、图形与连续性

如果生成字幕、画面文字、口播、口型、商品身份、UI 状态、图形层级或跨镜头连续性出现问题，提供针对性修复：

1. 先生成无内生文字的干净画面，再使用用户确认的字幕、MG 图形和独立口播。
2. 重生成无可读画面文字的视频，并简化口播句子。
3. 使用用户提供的准确台词制作确定性字幕、图形文字和口播。
4. 先审阅 MG 提示词/脚本，再重新生成动效。
5. 调整参考角色，或更换经用户认可的参考源，修复人物、商品、UI 或图形连续性。

在用户未确认修复路线或没有可用产出前，不得声称修复完成。

## 步骤 8：画布交付

用户要求把提示词、台词或任务放到画布时，创建简洁、可直接复制的提示词或脚本节点。明确写出参考素材标记、口播台词、镜头时间、字幕、MG 动效、图形文字和输出约束。用户要求纯提示词时，不得改成项目简报或解释性任务清单。

## 适用边界

适用于任何商品类型或服务类型的短口播广告，并由 LLM 自动组合真人/产品展示、参考视频结构、口播、字幕和 MG 动效，包括服饰、鞋包、美妆、食品、家居、数码、软件、教育产品、本地服务和工业产品。它不替代长篇剧情 TVC 策划、完整广告战役策略、纪录片制作或纯字幕编辑。
