## 🇨🇳 中文

面向任意商品、服务或产品类型的短口播广告制作技能。用户给出参考视频、产品图片、资料、音频、核心卖点或准确台词，技能先核验事实主张与参考素材限制，分析结构、节奏、演示逻辑与包装方式，再编写匹配时长的口播脚本，并向 LLM 下达统一制作要求、逐项验收结果。成片包含真人/产品展示、口播、字幕、动态排版、功能卡片、UI 状态、流程图、图形转场与混合叠加，不套固定模板。适用于服饰、美妆、食品、数码、家居、软件、教育、服务与工业产品等全品类短商业广告，不适用于长篇剧情 TVC、纪录片或纯字幕编辑。

### ✨ 能做什么

- 输入产品图 / 资料 / 成稿文案 → 输出匹配时长的短口播广告成片
- 按 10–15 秒结构编排：前三秒钩子或痛点 → 品类与具体利益点 → 可视化演示 → 已确认优惠 → 明确 CTA
- 要求 LLM 规划并执行动态排版、功能卡片、UI 状态、流程图与图形转场，MG 动效不套模板
- 自动核验价格、折扣、速度、保证、认证与效果主张，无法核实就改写为保守表达
- 区分「口播说出的信息」与「画面显示的信息」，按时长控制屏幕文字数量
- 参考素材只保留结构、节奏、动效语言与可复用视觉语言，画面重新生成，不做逐帧复制

## 🇬🇧 English

A short voiceover ad skill for any product, service or product category. You supply a reference video, product images, documents, audio, selling points or exact copy; the skill checks claims and reference limits, analyzes structure, pacing and demonstration logic, builds a duration-matched script, then issues one unified instruction for the LLM to execute and validates the result item by item. The finished cut combines presenter or product footage, voiceover, captions, kinetic typography, feature cards, UI states, diagrams, graphic transitions and hybrid overlays instead of a stock template. It covers fashion, beauty, food, electronics, household goods, software, education, local services and industrial products, but not long narrative TVC campaigns, documentaries or subtitle-only editing.

### ✨ What it does

- Product images, docs or exact copy in → a duration-matched short voiceover ad out
- Structures 10–15s spots as: 3-second hook or pain point → category and one or two concrete benefits → visual proof → confirmed offer → clear CTA
- Directs the LLM to plan and execute kinetic typography, feature cards, UI states, diagrams and graphic transitions — no stock MG template
- Verifies price, discount, speed, guarantee, certification and performance claims; unverifiable claims are rewritten conservatively
- Separates what the voiceover says from what the screen shows, and caps on-screen text to the runtime
- Keeps only structure, pacing, motion language and reusable visual logic from references; the actual frames are regenerated, never frame-copied
